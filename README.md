## 🎯 Perfil Profesional

Analista de Ciberseguridad enfocado en **Seguridad Ofensiva, Defensiva y Automatización (DevSecOps)**. Este repositorio contiene el código fuente de mi portfolio profesional y una selección curada de proyectos técnicos, herramientas de auditoría e investigaciones de seguridad.

## ✨ Arquitectura del Portfolio (V2.2 Overhaul)

- 🎨 **Pure Black Premium UI**: Rediseño minimalista de alto contraste centrado en la legibilidad técnica.
- 📐 **Tipografía de Ingeniería**: Uso de *Space Grotesk* para branding y *JetBrains Mono* para datos técnicos.
- ⚡ **Stack Moderno**: React 19 + Vite 8 + Tailwind CSS 4.
- 🛡️ **Security-First**: Implementación de políticas de seguridad (CSP) y protección contra Clickjacking.

## 🚀 Proyectos Destacados (Heavy Hitters)

### 1. [Web Vulnerability Scanner](https://github.com/Michel-Macias/Escaner-de-vulnerabilidades-web)
Herramienta profesional de auditoría web con motor headless (Playwright), crawler asíncrono y evasión de WAF. Especializada en detección de SQLi, XSS y RCE.

### 2. [Shapeshifter: Análisis Binario](https://github.com/Michel-Macias/Shapeshifter-Detector)
Ecosistema forense para la detección de amenazas mediante el análisis de *Magic Numbers* y reconstrucción heurística de DNA binario. Integración con VirusTotal v3.

### 3. [Lynis Hardening & Audit](https://github.com/Michel-Macias/lynis)
Ciclo completo de auditoría y endurecimiento de sistemas Linux. Automatización de remediaciones críticas y gestión de políticas de seguridad.

### 4. [CentinelaQR: Protección Quishing](https://github.com/MaciasIT/Centinela_PWA)
PWA avanzada para la mitigación de ataques de Quishing. Análisis de reputación de URLs en tiempo real mediante arquitectura serverless.
